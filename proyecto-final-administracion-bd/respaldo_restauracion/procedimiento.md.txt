# Respaldo y Restauración

## Crear respaldo

```bash
pg_dump -U postgres -d biblioteca_db -F c -f biblioteca.backup
```

## Restaurar

Crear una nueva base:

```sql
CREATE DATABASE biblioteca_restaurada;
```

Restaurar:

```bash
pg_restore -U postgres -d biblioteca_restaurada biblioteca.backup
```

El respaldo puede ejecutarse desde DBeaver utilizando la herramienta **Tools → Backup** siempre que esté configurado el cliente local de PostgreSQL (`pg_dump`). <Cite refs={["turn0search0","turn0search2"]}/>
